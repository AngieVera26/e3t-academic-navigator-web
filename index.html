Integración MCP

Tu calendario, conectado con inteligencia artificial ✧

El agente E3T Academic Navigator utiliza las herramientas MCP del proyecto para consultar semestres, semanas, eventos y próximos compromisos. La conexión validada actualmente se utiliza desde Copilot Chat en el entorno de GitHub Codespaces; esta página no simula una conversación ni afirma tener un chat integrado.

Cómo consultar al agente

Abre el proyecto en GitHub Codespaces, inicia el servidor Python en el puerto 8000 y verifica que el servidor MCP e3t-academic-navigator esté en ejecución. Después abre Copilot Chat en modo agente y escribe una de estas consultas:

¿Qué actividad académica está programada para la semana 15 del semestre 2026-2?

¿Cuál es la fecha límite de entrega de TG1 para el comité en el semestre 2026-2?

Muéstrame los próximos compromisos académicos del semestre 2026-2 a partir de hoy.
